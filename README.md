# pyrs
A source-to-source transpiler from Mypy-annotated Python to idiomatic Rust

## Retired

This project is deprecated and retired as of November 6, 2026. Its
Python-to-Rust transpiler goal is superseded by
[py2many](https://github.com/py2many/py2many). Future work will focus on
contributing to py2many, especially its Rust backend, through the
[personal fork](https://github.com/carlosferreyra/py2many).

This repository is retained as an archive of its history and
[research notes](docs/README.md), including the
[Python-to-Rust landscape](docs/python-rust-landscape.md). These documents
contain research and proposals, not implemented features.
